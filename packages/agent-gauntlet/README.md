# @agent-gauntlet/cli 🛡️

Universal multi-stack verification gauntlet & tamper-proof evidence authority for AI coding agents.

## Quick Start via NPX

Scaffold agent-gauntlet governance directly in your project without global installation:

```bash
npx @agent-gauntlet/cli init
```

Run verification and diagnostics:

```bash
npx @agent-gauntlet/cli verify --task-id 001-bootstrap
```

Validate documentation & OKF metadata:

```bash
npx @agent-gauntlet/cli okf validate
```

See [GitHub Repository](https://github.com/rolfmadsen/agent-gauntlet) for documentation, standards, and architecture details.
